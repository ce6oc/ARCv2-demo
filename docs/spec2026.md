# 🗄️ Схема Базы Данных для ARCFlow

Ниже представлена полная схема базы данных (MySQL), разработанная с учётом всех обсуждённых требований: гибридная модель доступа (гость/зарегистрированный), мультиязычность, структура `IDEAS.md`, ветвление сценариев и аналитика.

## 📋 Детальная Структура Таблиц

### 1. `users` (Преподаватели и Администраторы)
| Поле | Тип | Описание |
|------|-----|----------|
| `id` | BIGINT UNSIGNED | Primary Key |
| `email` | VARCHAR(255) | Уникальный email |
| `password_hash` | VARCHAR(255) | Хэш пароля |
| `name` | VARCHAR(255) | Имя преподавателя |
| `role` | ENUM('teacher', 'admin') | Роль пользователя |
| `is_verified` | BOOLEAN | Подтверждён ли статус педагога |
| `created_at` | TIMESTAMP | Дата регистрации |
| `updated_at` | TIMESTAMP | Дата обновления |

### 2. `class_groups` (Виртуальные Классы)
| Поле | Тип | Описание |
|------|-----|----------|
| `id` | BIGINT UNSIGNED | Primary Key |
| `teacher_id` | BIGINT UNSIGNED | FK → users.id |
| `class_name` | VARCHAR(255) | Название класса |
| `class_code` | VARCHAR(20) | Уникальный код для входа (напр. `SPACE-2024-A`) |
| `registration_link` | VARCHAR(500) | Полная ссылка для регистрации |
| `grade_level` | VARCHAR(50) | Возрастная группа (напр. `2-4`) |
| `description` | TEXT | Описание класса |
| `is_active` | BOOLEAN | Активен ли класс |
| `settings` | JSON | Настройки (пароль, аватары, гостевой доступ) |
| `created_at` | TIMESTAMP | Дата создания |
| `updated_at` | TIMESTAMP | Дата обновления |

**Индексы:** `class_code` (UNIQUE), `teacher_id`, `is_active`

### 3. `students` (Зарегистрированные Ученики)
| Поле | Тип | Описание |
|------|-----|----------|
| `id` | BIGINT UNSIGNED | Primary Key |
| `class_id` | BIGINT UNSIGNED | FK → class_groups.id |
| `nickname` | VARCHAR(100) | Никнейм (уникален в рамках класса) |
| `password_hash` | VARCHAR(255) | Хэш пароля/PIN |
| `avatar_id` | VARCHAR(50) | ID выбранного аватара |
| `is_guest` | BOOLEAN | Флаг: был ли создан как гость |
| `session_token` | VARCHAR(255) | Токен для временного доступа |
| `last_active_at` | TIMESTAMP | Последняя активность |
| `created_at` | TIMESTAMP | Дата регистрации |
| `updated_at` | TIMESTAMP | Дата обновления |

**Индексы:** `class_id`, `nickname` (UNIQUE на class_id), `session_token`

### 4. `lessons` (Метаданные Уроков)
| Поле | Тип | Описание |
|------|-----|----------|

| `subject` | VARCHAR(100) | Предмет |

## 🔗 Отношения между Таблицами

| Отношение | Тип | Описание |
|-----------|-----|----------|
| `users` → `class_groups` | 1:N | Один учитель создаёт много классов |
| `users` → `lessons` | 1:N | Один учитель создаёт много уроков |
| `class_groups` → `students` | 1:N | В одном классе много учеников |
| `lessons` → `lesson_translations` | 1:N | Один урок имеет много переводов |
| `students` → `lesson_results` | 1:N | Один ученик проходит много уроков |
| `class_groups` → `lesson_results` | 1:N | Результаты группируются по классам |
| `students` → `student_progress` | 1:1 | Один профиль прогресса на ученика |

## 🌐 Мультиязычность: Как Это Работает

### 1. Создание Урока
- Учитель выбирает **основной язык** урока
- Контент сцен (`scenes`) сохраняется в `lesson_translations` для этого языка
- Поле `is_default = true` для основного языка

### 2. Добавление Перевода
- Учитель (или другой автор) может добавить перевод
- Создаётся новая запись в `lesson_translations` с другим `language_code`
- Структура `scenes` сохраняется, текст внутри сцен переводится

### 3. Прохождение Урока
- Ученик видит урок на языке, который:
  1. Выбрал явно в настройках, ИЛИ
  2. Совпадает с языком интерфейса, ИЛИ
  3. Язык по умолчанию урока
- В `lesson_results` сохраняется `language_code` для аналитики

### 4. Пример Запроса для Получения Урока
```sql
SELECT 
    l.id,
    lt.title,
    lt.description,
    lt.scenes,
    lt.language_code
FROM lessons l
JOIN lesson_translations lt ON l.id = lt.lesson_id
WHERE l.id = ?
  AND lt.language_code = ?  -- Предпочитаемый язык
  AND lt.is_default = ?     -- Или язык по умолчанию
ORDER BY lt.is_default DESC
LIMIT 1;
```

## 🔐 Безопасность и Приватность

| Аспект | Реализация в БД |
|--------|-----------------|
| **Минимизация данных** | В `students` нет email, ФИО, телефона |
| **Пароли учеников** | Хранится только `password_hash` (bcrypt) |
| **Гостевой доступ** | `lesson_results` поддерживает `is_guest = true` + `session_token` |
| **Аудиофайлы** | URL в `scene_responses`, доступ по signed URL (не в БД) |
| **Удаление данных** | `class_groups.is_active = false` + каскадное удаление учеников |
| **Экспорт данных** | Все результаты ученика можно выгрузить по `student_id` |

## 📈 Аналитические Возможности

### Запрос: Средняя успеваемость по классу
```sql
SELECT 
    lr.lesson_id,
    COUNT(*) as total_students,
    AVG(JSON_EXTRACT(lr.score, '$.percentage')) as avg_score,
    AVG(lr.duration_seconds) as avg_duration
FROM lesson_results lr
WHERE lr.class_id = ?
GROUP BY lr.lesson_id;
```

### Запрос: Проблемные сцены (где больше всего ошибок)
```sql
SELECT 
    JSON_EXTRACT(sr.value, '$.sceneId') as scene_id,
    COUNT(*) as total_attempts,
    SUM(CASE WHEN JSON_EXTRACT(sr.value, '$.isCorrect') = true THEN 1 ELSE 0 END) as correct_count
FROM lesson_results lr,
JSON_TABLE(lr.scene_responses, '$[*]' COLUMNS(value JSON PATH '$')) as sr
WHERE lr.lesson_id = ?
GROUP BY scene_id
ORDER BY correct_count ASC;
```

### Запрос: Прогресс ученика во времени
```sql
SELECT 
    DATE(lr.start_time) as date,
    COUNT(*) as lessons_completed,
    AVG(JSON_EXTRACT(lr.score, '$.percentage')) as avg_score
FROM lesson_results lr
WHERE lr.student_id = ?
GROUP BY DATE(lr.start_time)
ORDER BY date ASC;
```

## 🚀 Рекомендации по Реализации в Laravel

### 1. Модели Eloquent
```php
// Lesson.php
class Lesson extends Model {
    public function translations() {
        return $this->hasMany(LessonTranslation::class);
    }
    public function results() {
        return $this->hasMany(LessonResult::class);
    }
    public function getContentAttribute($lang = 'ru') {
        return $this->translations()
            ->where('language_code', $lang)
            ->first() 
            ?? $this->translations()->where('is_default', true)->first();
    }
}

// ClassGroup.php
class ClassGroup extends Model {
    public function teacher() {
        return $this->belongsTo(User::class, 'teacher_id');
    }
    public function students() {
        return $this->hasMany(Student::class);
    }
    public function results() {
        return $this->hasMany(LessonResult::class);
    }
}

// Student.php
class Student extends Model {
    public function classGroup() {
        return $this->belongsTo(ClassGroup::class, 'class_id');
    }
    public function results() {
        return $this->hasMany(LessonResult::class);
    }
    public function progress() {
        return $this->hasOne(StudentProgress::class);
    }
}
```

### 2. Миграции (Пример)
```php
// create_lesson_translations_table.php
Schema::create('lesson_translations', function (Blueprint $table) {
    $table->id();
    $table->foreignId('lesson_id')->constrained()->onDelete('cascade');
    $table->string('language_code', 10);
    $table->string('title');
    $table->text('description');
    $table->string('author')->nullable();
    $table->longText('scenes'); // JSON
    $table->boolean('is_default')->default(false);
    $table->timestamps();
    
    $table->unique(['lesson_id', 'language_code']);
    $table->index('is_default');
});
```

### 3. Кастомизация JSON в MySQL
Используйте виртуальные колонки для частых полей из JSON:
```php
// В миграции lesson_results
$table->json('score');
$table->virtualAs('JSON_EXTRACT(score, "$.percentage")', 'score_percentage');
// Теперь можно индексировать score_percentage для быстрой аналитики
```

## 📊 Итоговая Сводка

| Компонент | Таблица | Ключевая Фича |
|-----------|---------|---------------|
| Пользователи | `users` | Только преподаватели |
| Классы | `class_groups` | Уникальные коды доступа |
| Ученики | `students` | Гибридная модель (гость/зарегистрированный) |
| Уроки | `lessons` + `lesson_translations` | Мультиязычность через отдельные записи |
| Контент | `lesson_translations.scenes` | JSON из `IDEAS.md` |
| Результаты | `lesson_results` | JSON `scene_responses` из `IDEAS.md` |
| Прогресс | `student_progress` | Лонгитюдная аналитика |
| Достижения | `achievements` | Геймификация |
| Языки | `languages` | Справочник локалей |

Эта схема готова к реализации в Laravel + MySQL и полностью покрывает все требования: структуры из `IDEAS.md`, гибридный доступ, мультиязычность, аналитику и масштабируемость.
